These days I work on enterprise service-management (ITSM) platforms at a multinational technology company. Before that, I built internal web platforms for a large Malaysian property & construction group, working across Django REST APIs, SvelteKit and Next.js frontends, and deployments on GCP Cloud Run.

I'm more product engineer than code-writer. What matters is the outcome users actually get, so I treat UI/UX, reliability and features as part of the craft, not afterthoughts.

### Enterprise work

- **HR performance platform**: Django REST backend (150+ endpoints) and a SvelteKit frontend (70+ routes, role-based UIs), with Azure AD SSO, JWT auth, and GCP Cloud Tasks driving scheduled sync and notification jobs.
- **Event RSVP platform**: Next.js and PostgreSQL/Prisma, load-tested to ~12k RSVPs an hour on auto-scaling Cloud Run, with a Pub/Sub fan-out pipeline for email and WhatsApp confirmations, behind a glassmorphism UI.
- **Incident-management system**: decoupled Next.js frontend and Django API with Azure AD SSO, Celery/Redis background jobs and server-side PDF report generation.

Outside the core stack, I tinker with generative AI: image generation with Stable Diffusion and voice synthesis with So-VITS-SVC. Agentic workflows and MCP have also become a growing part of my life, both in and out of work.

Research-wise, I co-authored [HeatGen](https://github.com/Shanahan-Suresh/segp-group4a-deep-learning-network), a neural-network tool for predicting heat-absorbing pavement materials, published in the *Journal of Engineering Science and Technology* ([paper](https://jestec.taylors.edu.my/Vol%2018%20Issue%202%20April%202023/18_2_16.pdf)).
